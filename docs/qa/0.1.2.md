## UI / 体验

- 触屏滑块常显可抓取柄，歌曲操作按钮点击区域至少 44px，分段控件触摸高度增至约 44px。
- 三类内置弹层新增 Tab 焦点约束、后台 inert 与返回焦点；确认弹窗原有焦点处理保留。
- 播放按钮新增缓冲状态与 `aria-busy`；无障碍标签/状态随播放、收藏、随机、循环更新。
- 推荐失败提供重试；首页最近播放与推荐改为独立容器更新。
- 页面加入 History API 后退功能。
- 新增 GitHub Actions 测试/构建检查；暂未提供 lockfile（构建环境不具备 npm Registry 缓存）。

## 已完成的自动化验证

- `npm run check`：24 项 Node.js 测试 + JS 语法检查。
- 涵盖 LRC、歌曲与歌单规范化、API 失败/降级、队列播放模式/索引、存储错误恢复与模板渲染。

## 必须继续进行的验收

- 本环境无法离线安装 Vite，尚未实测生产构建；以 GitHub Actions 结果为准。
- Android Chrome、iOS Safari、桌面 Chromium/Firefox 的键盘焦点、弹层动画、音量/进度触控、320–1024px 布局。
- IndexedDB v1→v2 真实浏览器升级、百首以上本地音频与存储配额不足场景。
- 真实 API 的 CORS、业务码差异、版权/会员限制、音频 CDN 和断网恢复。
- 歌单含不可用曲目时，服务端没有返回歌曲详情的 ID 无法在客户端凭空还原。
