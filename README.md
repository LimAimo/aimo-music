# Aimo Music

**当前版本：0.3.0** · [更新日志](CHANGELOG.md) · [音乐项目设计映射](MUSIC_SCOPE.md)

AimoChat 视觉规范下的纯前端网页音乐播放器。无需账号或服务端数据库，支持网易云兼容接口和自定义 JSON 适配的多 API 管理、故障转移与歌曲来源隔离，也能导入自己拥有的本地音频文件。用户收藏、历史与队列保存在当前浏览器，本地文件存放在 IndexedDB。

## 本地开发

需要 Node.js 20.19+ 或 22.12+。在本目录执行：

```bash
npm ci --prefix client
npm run dev
```

打开 `http://localhost:3200`。开发模式默认经 Vite 把 `/music-api/` 转发到 `https://music.20110208.xyz/`；不需要单独开发一个后端。

不装 Vite 时也可以进入 `client/` 用任意静态 HTTP Server 提供目录，例如 `python3 -m http.server 3200`；这时采用浏览器直连 API，必须满足目标服务的 CORS 策略。不要直接双击打开 `file://`，ES modules 可能被浏览器禁止。

## 测试与构建

```bash
npm run check
npm run build
```

`npm run check` 使用 Node.js 内置测试器并检查脚本语法，无需外部测试依赖；`npm run build` 需要 Vite。提交后 GitHub Actions 会安装依赖、执行测试并检查生产构建。静态部署上传 `client/dist` 内容，支持网站根路径与子路径（相对资源 URL）。站点使用 HTTPS。

## 仅前端部署的边界

默认线上使用浏览器直连 `https://music.20110208.xyz`。浏览器的 CORS、目标域名可用性、音频 CDN 的播放限制必须由真实部署环境验证。本会话的执行环境无法解析该域名，因此尚未完成在线端到端播放验证。

如果 API 不允许跨域：

1. 最简单的办法是让 API 服务端放行你的前端域名；
2. 或让你的静态托管 / Nginx 将 `/music-api/` 转发到目标 API，再在页面「设置 → 连接方式」选择本站代理。

普通静态文件**不能自行消除 CORS 限制**。任何需要服务端保存的 API Key、Cookie 或用户级鉴权都不能直接加入浏览器代码。`/song/url/v1` 仅对实际可访问的授权资源播放，客户端不会伪造会员身份或绕过版权限制。歌曲封面和音频来自第三方服务器，会向对应服务发送正常网络请求。

## 播放行为说明（0.1.2）

- **手动下一首**无论是否开启单曲循环，都尝试前进；**自然播放结束**时单曲循环才重播本曲。
- 随机模式采用一轮不重复的播放顺序，上一首返回实际播放历史。列表循环开启时，随机顺序用完会重新洗牌。
- 歌单按服务端 `trackIds` 补齐歌曲明细；服务端无法提供的信息会造成展示数量低于原始歌单总数，此时页面显示已加载数与标称总数。
- 最近播放只在音频实际开始播放后写入，不把没有地址或播放被阻止的歌曲当作播放成功。
- 原本的本地文件通过 IndexedDB v2 自动迁移：文件 Blob 仍保留在文件表，歌曲元数据在独立表查询。

## 验证限制

已提交 `client/package-lock.json` 锁定依赖树，GitHub Actions 使用 `npm ci` 构建。在没有 npm Registry 缓存的离线环境中依然无法下载 Vite，但远端工作流已能安装并构建。在线音乐 API、移动端触控和浏览器焦点仍需要在实际运行环境验证，详见 [质量记录](docs/qa/0.1.2.md)。

## 多 API 与安全限制

默认 API 仍保留旧版兼容地址；CurrentStation 新 `/cm/ncm` 路由根据提供的目录作为**手动启用的预设**，并未在线实测。自定义 JSON 映射不执行代码、不保存 Bearer/管理员凭据，不支持带秘密密钥的接口直连。只有资源命名空间一致时才允许已有歌曲切换备用来源，避免不同平台 ID 碰撞。仅对网络故障、网关不可用等可恢复问题执行降级，不能绕过版权、会员或上游鉴权。

## CurrentStation 与诊断页面

0.2.1 默认使用 CurrentStation `/cm/ncm`，兼容扁平搜索结果和逐行歌词；旧版默认 API 配置自动迁移，用户自定义节点保留。浏览器中可直接访问 `/diagnostics/` 运行只读 API 检测，应用内不提供入口。诊断页不会请求账号令牌或下载音频；播放地址是否存在取决于上游。

## 0.3.0 本地数据与恢复说明

播放历史与自定义歌单保存在当前浏览器的 IndexedDB，应用不设置历史记录条数上限，但仍受设备存储配额限制。旧版本的收藏、最近播放、播放队列和音乐 API 配置继续从原有 localStorage 读取，不会在升级时主动清除。

在「音乐库 → 我的歌单」可以创建、导入、导出歌单，也可以「备份全部 / 恢复备份」。完整备份覆盖歌单、收藏、队列、设置和完整播放历史，但**不包含音频文件二进制内容**；跨设备恢复时需要重新导入本地音频。智能歌单动态读取浏览器可用的收藏、播放历史和本地音乐，不会自动访问用户未收藏的在线搜索结果。联网恢复后的数据刷新不会绕过第三方 API 的限制或音频版权要求。

桌面快捷键可在设置中修改组合键、作用范围以及是否启用。浏览器保留的按键不能覆盖，冲突时需调整后方可保存。移动端手势和背景动效均考虑系统减少动态效果设置。
